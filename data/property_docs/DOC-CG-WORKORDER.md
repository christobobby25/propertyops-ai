# Cedar Grove Work-Order Procedures

## Request details and approval
<!-- section_id: DOC-CG-WORKORDER-S01 -->

A new work order requires the issue category, description, unit, and explicit entry preference. Unit and property are resolved from the signed-in resident. Show the proposed request and obtain explicit approval before creation. Approval to create a ticket does not grant entry permission.

## Existing requests
<!-- section_id: DOC-CG-WORKORDER-S02 -->

Before creating a request, check active work orders for the same unit and issue. Open, scheduled, and in-progress requests are active. Completed and cancelled requests are historical. Offer the existing matching request first; ask whether a same-category report is a different issue when unclear.

## Changes and unsupported information
<!-- section_id: DOC-CG-WORKORDER-S03 -->

The MVP supports reading and creating work orders. Cancellation, scheduling changes, vendor dispatch, repair-cost quotes, and rent-credit decisions require property staff. Do not promise reimbursement or an arrival time that is absent from the records.
