# Lakeview Work-Order Procedures

## Request details and approval
<!-- section_id: DOC-LV-WORKORDER-S01 -->

A new work order requires the issue category, description, unit, and explicit entry preference. Unit and property are resolved from the signed-in resident. Show the proposed request and obtain explicit approval before creation. Approval to create a ticket does not grant entry permission.

## Existing requests
<!-- section_id: DOC-LV-WORKORDER-S02 -->

Check active work orders for the same unit and issue before creating a request. Open, scheduled, and in-progress requests are active. Completed and cancelled requests are historical. Offer the existing matching request first and clarify potentially different issues.

## Changes and unsupported information
<!-- section_id: DOC-LV-WORKORDER-S03 -->

The MVP supports reading and creating work orders. Cancellation, scheduling changes, vendor dispatch, repair-cost quotes, and rent-credit decisions require property staff. Do not promise reimbursement or a technician arrival time absent from current records.
